# Quiz Application

A Java-based GUI Quiz Application designed to provide an interactive quiz experience with multiple categories, a timer, navigation controls, and automatic score calculation.

## Features

- Multiple quiz categories
- Interactive Java GUI
- 60-second quiz timer
- Next and Previous question navigation
- Skip question option
- Answer tracking
- Automatic score calculation
- User-friendly interface

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming

## How to Run

1. Make sure Java JDK is installed on your system.
2. Download or clone this repository.
3. Open the project in a Java IDE such as IntelliJ IDEA, Eclipse, or VS Code.
4. Compile `QuizApp.java`.
5. Run the `QuizApp` class.

## Project Structure

```text
quiz-application-java/
└── QuizApp.java
```

## Purpose

This project was developed to practice Java programming, GUI development, event handling, and basic application logic.
